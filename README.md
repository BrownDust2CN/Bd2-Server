## 进入服务器步骤

1. **下载官方客户端**：官网下载官方客户端（PC 端）。
2. **安装补丁**：将补丁包内的DLL 覆盖到游戏目录
3. **注册账号**：进入游戏登录界面，在账号栏直接输入账号密码即可完成自动注册登录。
4. **加载资源**：首次进入需要下载完整资源包，请确保网络畅通并预留足够存储空间。

## 常见问题 (FAQ)

* **Q: 提示“网络连接中断”或错误代码怎么办？**  
  *A:* 请检查是否已按教程正确安装补丁，或确认服务器当前是否处于维护状态（留意Discord内公告）。

* **Q: 会影响官方账号吗？**  
  *A:* 完全不会。测试服采用独立的网络地址与本地客户端配置，与官方客户端互不干扰。

* **Q: 游戏内遇到 Bug 怎么反馈？**  
  *A:* 请在 Discord 对应的 `#bug-report` 频道发送截图与复现步骤。
