## 进入服务器步骤 / Getting Started

1. **下载官方客户端 / Download Official Client**  
   前往游戏官方网站下载官方 PC 端客户端。  
   *Download and install the official PC game client from the official website.*

2. **安装补丁 / Apply Patch**  
   下载 Releases 补丁包，将解压后的 DLL 文件覆盖复制到游戏根目录中。  
   *Download the patch package from Releases, then extract and copy the DLL files into the game root directory.*

3. **注册与登录 / Account Registration & Login**  
   启动游戏进入登录页面，直接在账号与密码输入栏键入自定义凭据，即可自动完成注册并登录。  
   *Launch the game and enter your desired username and password on the login screen to automatically register and log in.*

4. **加载资源 / Download Assets**  
   首次进入游戏需在线下载完整静态资源包，请确保网络畅通并预留足够硬盘空间。  
   *The client will download game assets on the first startup. Please ensure a stable internet connection and sufficient disk space.*

## 常见问题 / FAQ

- **Q: 提示“网络连接中断”或弹出错误代码？ / Getting "Network Connection Interrupted" or error codes?**  
  *A:* 请检查补丁 DLL 是否已正确放入游戏根目录，或确认本地防火墙设置；同时关注 Discord 公告确认服务器是否正在维护。  
  *A:* *Ensure the patch DLL is correctly placed in the game directory. Check your local firewall settings, and monitor Discord announcements to see if the server is undergoing maintenance.*

- **Q: 会影响官方账号吗？ / Will this affect my official account?**  
  *A:* 完全不会。测试服采用独立的自建网络接口与数据存储层，与官方服务器互不干扰、互不连通。  
  *A:* *Not at all. The private community server uses isolated network endpoints and standalone databases, operating completely independently from official servers.*

- **Q: 游戏内遇到 Bug 怎么反馈？ / How do I report in-game bugs?**  
  *A:* 请前往 Discord 对应的 `#bug-report` 频道，发送相关截图及复现步骤。  
  *A:* *Please join our Discord and post screenshots alongside detailed reproduction steps in the `#bug-report` channel.*

- **Q: 服务器收费吗？真的完全免费吗？ / Is it free? Are there any hidden costs?**  
  *A:* 完全免费！本项目为纯公益性质，没有任何内购、赞助特权或付费项目。如果在 Discord 为我们的服务器进行 Server Boosting（服务器助力），就是对我们最大的认可与支持！  
  *A:* *100% Free! This project is purely non-profit with zero paywalls, microtransactions, or paid VIP tiers. Boosting our Discord server is the best way to show your support and appreciation!*
